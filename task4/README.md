# Задание 4. Проектируем систему мониторинга

«GoFuture» стремится быстро запускать решения для партнёров в новых регионах с полной изоляцией данных и кастомизацией
функциональности. Поэтому разработайте дизайн мультитенантной платформы, который будет включать модель изоляции данных
между партнёрами, IAM-систему с ролевым доступом и SSO, автоматизированный процесс подключения новых партнёров (
onboarding) и систему мониторинга мультитенантного окружения.

## В результате у вас должно получиться

- Диаграммы С2 (или C3 при необходимости), показывающие решение с внедрённой IAM-системой, мониторингом и потоками
  данных, отражающих логику процесса онбординга новых партнёров.
- Таблица с выбором ролей и необходимыми уровнями доступа к данным.

Загрузите получившиеся артефакты в директорию Task4 вашего репозитория.
